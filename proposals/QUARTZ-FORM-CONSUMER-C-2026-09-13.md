## Delivered behavior

- One source-bound projection precedes enclosure-copy consumers, cache identity,
  neighbour preparation, route selection and representative population emission.
  It reads the original non-enumerable ledger, validates identity/birth/coverage,
  and preserves absence, null and descriptor removal.
- Supported forms are untwinned, fluid-grown ordinary and doubly terminated
  prisms, and the inventoried sceptre/gwindel descriptor routes. Special shapes
  begin at the observed classifier selection, not at a retrospectively labelled
  resorption boundary. Valid zero cap fractions remain zero.
- Geometry variation uses immutable source identity, including string identities.
  Collection display IDs remain separate from source IDs and enclosure/picking
  namespaces. Special geometry caches cannot borrow a later live cap or twist.
- Split/fabric/air intervals, unknown twins, other habits/polymorphs, CDR parent
  inheritance, hollow casts and enclosed quartz remain explicit latest-form
  display fallbacks. Missing old histories remain unknown.
- Within supported coverage, undated attachment depth, neighbour contact cuts,
  sector/polar overprints and deformation application are uniformly withheld.
  Replay tooltips disclose the selection and omissions. Library/Record Player
  and zone history show a clearly identified coverage summary; the Record Player
  itself continues to display growth zones.

Recorded dimensions, chemistry, inclusions, coatings and enclosure lifecycle
retain their independent authorities. Face distances, accessory-face selection,
striations, chamfers and population members remain representative display
conventions. Neither their appearance nor the ledger establishes physical
per-face growth histories.

first implementation at **3/5** for a real delayed-deformation leak. The actual
classifier can skip a crystal below `DEFORM_MIN_UM`, apply the bend after later

when the model first applied deformation. See the
[pinned classifier](https://github.com/Syntaxswine/vugg-simulator/blob/0f0be7f7f94c9f8d5b2f7806504914c818f2da93/js/45-morphology.ts#L665-L681).

The correction uniformly withholds this overprint in recorded-form mode and
preserves the source tag. The reviewer independently reproduced the delayed
threshold case against the exact classifier and revised projection, then awarded
the code **4/5 PASS** with no remaining code blocker. The visual/resource review
also reached **4/5 PASS** after correcting an instrument label: `add_zone`
accepts aspect 0.4, so replay reconstructs 8 × 3.2 mm despite the control's
assigned live dimensions of 8 × 4 mm. The rig now derives both independently,
and explicitly measures an empty state geometry map before warm/hit timings.
All 11 regenerated images and their hashes, selections and timings were checked
by the reviewer. Final release evidence acceptance remains pending below.

## Resource and scientific limits

On this Windows/RTX 3080 workstation, the regenerated captures measured:

| Operation | Five production frames | Six one-crystal controls |
| --- | ---: | ---: |
| Empty state geometry-map rebuild | 89.2–182.2 ms | 1.8–12.9 ms |
| Warm forced mesh rebuild | 58.4–131.2 ms | 1.0–6.6 ms |
| Immediate cached mesh sync | 6.0–13.1 ms | 0.2–0.5 ms |
| First post-run full scene refresh | 837–950 ms | 193–281 ms |
| Full repeated replay refresh | 373.7–507.7 ms | 1.8–2.3 ms |

The cold measurement empties only `state.geomCache`, the map used by covered
prism/cap/twist routes. Every manifest records zero entries at its cold start
and repopulation afterward. Scene, material, legacy per-crystal and GPU caches
remain warm. Neither this nor the first post-run refresh measures process-cold
startup or GPU compilation. Mesh calls include form-history projection and
validation; the larger full repeated refresh cost is reported separately.
Separate GPU frame timings remain in each manifest. These are single serial
observations, not performance guarantees for slower computers.

Unknown chronology remains unknown. In particular, general deformation
